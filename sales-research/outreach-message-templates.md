# 企業営業：掲載確認・関係構築フェーズの連絡文テンプレート

> **社内資料。サイトには公開しない。**
> STEP3方針（`outreach-targets.md`参照）の通り、最初の接触は「広告掲載しませんか」ではなく「掲載内容のご確認」を入口にする。ヒアリングは初回メッセージに詰め込まず、返信があった後の2通目以降で行う。

---

## 使い方

1. `outreach-targets.md` から対象企業を選ぶ
2. その企業の Oppick 掲載ページURLを確認する（`https://uto-inc.jp/{market-slug}/company/{slug}/`）
3. 企業の公式サイトにある問い合わせフォーム、または直接メールアドレスが分かればそちらへ送る
4. 下記「メッセージ1」をベースに、`【　】`内を差し替えて送信する
5. 返信が来たら「メッセージ2」をベースにヒアリングへ進む

**フォームに件名欄がある場合**は「メッセージ1」の件名を使う。フォームが本文のみの場合は本文冒頭に用件が分かるよう先頭2行はそのまま残す。

---

## メッセージ1｜初回接触（掲載確認・情報更新依頼）

**目的**：関係構築の入口を作ること。ヒアリングも売り込みもしない。返信のハードルを下げることを最優先にする。

**件名（メール・件名欄がある場合）**
```
【掲載内容のご確認】大阪の法人向けサービス比較サイト「Oppick」より
```

**本文**
```
【会社名】ご担当者様

突然のご連絡失礼いたします。
大阪府を中心とした法人向けサービス会社の比較サイト「Oppick」を運営しております、Oppick運営チームと申します。

このたび、公開されている情報をもとに、貴社を【市場名（例：業務用エアコン工事）】会社の一社として下記ページにご紹介させていただいております。

▼ 掲載ページ
【掲載ページURL】

掲載にあたっては貴社公式サイトの情報のみを基に整理しており、正確性には努めておりますが、内容に誤りや古い情報が含まれている可能性もございます。
つきましては、下記についてご確認いただけますと幸いです。

・掲載内容に事実と異なる点がないか
・追加でご紹介したい強み・実績・対応内容などがないか

もし修正やご要望がございましたら、本メールへの返信、または下記フォームよりお知らせください。
（掲載は無料で行っており、現時点で費用は一切発生いたしません）

▼ 掲載情報の修正依頼フォーム
https://uto-inc.jp/listing-correction/

なお、Oppickの運営方針（公開情報のみを根拠に整理し、根拠のないランキング表現は行わない等）は下記に記載しております。
https://uto-inc.jp/methodology/

お忙しいところ恐れ入りますが、ご確認のほどよろしくお願いいたします。

--
Oppick運営チーム
大阪法人向けサービス比較メディア「Oppick」
https://uto-inc.jp
eisuke@uto-inc.jp
```

**フォーム用・短縮版（文字数制限があるお問い合わせフォーム向け）**
```
大阪の法人向けサービス比較サイト「Oppick」（https://uto-inc.jp）を運営しております、Oppick運営チームと申します。

公開情報をもとに貴社を【市場名】の一社としてご紹介しております（掲載ページ：【掲載ページURL】）。
掲載内容に誤りや古い点がないか、また追加でご紹介したい強み・実績等がございましたらお知らせいただけますと幸いです。掲載は無料です。

ご確認のほどよろしくお願いいたします。
Oppick運営チーム（eisuke@uto-inc.jp）
```

## メッセージ2｜返信があった後のヒアリング

**発動条件**：企業側から何らかの返信（修正依頼・確認OK・質問など）があった後に送る。ここで初めて集客状況を尋ねる。

**方針**：
- 質問は一度に全部聞かない。8項目（メモの4章）を2〜3個ずつ、会話の流れに乗せて聞く
- 「なぜ聞くのか」を必ず添える（比較サイトとして良い情報を届けたいため、という文脈に乗せる）
- 「掲載料を払ってください」という言葉は絶対に使わない。この段階ではまだ無料

**本文（修正依頼への返信を受け取った後の例）**
```
【会社名】ご担当者様

ご返信いただきありがとうございます。
ご指摘いただいた内容を確認のうえ、掲載ページを更新いたしました。

▼ 更新後のページ
【掲載ページURL】

もしよろしければ、今後より読者に役立つ形で情報を整理していくために、いくつか教えていただけますと幸いです（差し支えない範囲で結構です）。

・現在、貴社ではどのような経路からのお問い合わせが多いですか（紹介／自社サイト／ポータルサイト／広告など）
・Web経由の集客について、課題に感じていらっしゃることはありますか
・Oppickのような比較サイトへの掲載について、どのような形であれば価値を感じていただけそうですか
　（例：問い合わせが実際に来た分だけ費用が発生する形／月額固定で目立つ場所に掲載される形　など）

現時点ではサイトを立ち上げたばかりでアクセスはまだ多くありませんが、今後アクセスが増えてきた段階で、貴社にとって意味のある形でのご提案（送客の優先度を上げる、PR枠でより詳しくご紹介する等）ができればと考えております。

お手すきの際にご返信いただけますと幸いです。

--
Oppick運営チーム
https://uto-inc.jp
```

## 個社対応のヒント

Aランク企業については `sales-research/{market}.md` の「4. Aランク企業 詳細分析」に、その企業固有の「提案の切り口」「想定される反論」が既にまとめてある。メッセージ1の【　】を埋める際、可能であればその企業ならではの強み（例：晃洋厨機なら「保証を明記している数少ない会社」）に軽く触れると、テンプレート感が薄れ返信率が上がりやすい。ただし初回メッセージは短さを優先し、無理に個社カスタマイズで長くしない。

## 記録の取り方

メモ6章の通り、返信内容・断られた理由は必ず記録する。`outreach-targets.md`の各社の行に「返信有無／反応メモ」列を追記していく形を推奨（次回、進捗が出た時点でテンプレート化する）。
