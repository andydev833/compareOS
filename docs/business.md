# 事業方針

## 目的

大阪を中心に、必要に応じて関西まで対象を広げた**地域特化型比較サイト**を複数展開する。
サイトの目的は単なるSEO流入ではなく、以下の導線を作ることである。

```
検索
  ↓
比較サイト流入
  ↓
サービス・企業比較
  ↓
問い合わせ
  ↓
掲載企業への送客
  ↓
掲載課金・PR掲載・スポンサー・その他収益化
  ↓
将来的に売上改善サービスへ接続
```

したがって「ユーザーが比較・意思決定できる構造化された比較DB型サイト」を作る前提で設計する。
SEO記事量産サイトは目指さない。

## v1.0のスコープ

**目的**：1市場を入力すると、調査 → JSON生成 → サイト生成 → Validation → SEO Check → Build が
安定して動く開発環境をローカルに完成させる。GitHubへの自動Push・PR作成・自動公開は範囲外。

達成すべき一連の流れ：

1. 市場定義
2. 市場・SERP・競合調査
3. 掲載候補企業調査
4. 調査結果保存（research.md）
5. 構造化JSON生成（market.json / companies.json / keywords.json）
6. サイト戦略設計（strategy.md）
7. ページ構成生成（pages.json）
8. コンテンツ生成
9. Webサイトへ反映
10. SEOチェック
11. AEO/GEO観点チェック
12. データValidation
13. build
14. エラー修正
15. 最終レポート生成

## v1.0では作らないもの（過剰設計禁止）

- 複雑なマルチエージェント基盤
- ベクトルDB・独自RAG基盤
- Kubernetes等の複雑なインフラ
- 複雑なバックエンド・管理画面・ログイン・CRM
- Search Console自動連携
- 自動営業・自動メール送信・自動PR作成
- 完全自動デプロイ

これらはv1.0が安定稼働した後のPhase 2以降で検討する。
