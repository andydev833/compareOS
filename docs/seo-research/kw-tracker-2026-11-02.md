## 0. 読み方と限界

- クエリ別データは、表示回数が少ない匿名化クエリを含まない。市場ごとの「可視クエリ表示計」は、見えているクエリの表示回数の合計。社名を含む語や会社ページへの表示も含むため、市場ページの表示回数と直接は比べられない（AED・業務用エアコン・厨房機器は、ページ表示に比べてほとんど見えていない）。
- ページ別とクエリ別は結合できない。市場へのクエリの割り当ては、語句による機械的な分類（例：「防音」を含む→防音工事）で、手作業で確認していない。
- 「ブランド・社名の語」（掲載企業の名前を含む検索語）は、重点KW案から除いている。
- 検索ボリュームは未確認。**キーワードボリュームの確認はあなたの作業**（`/create-market` Phase 0 の手動ステップ）。
- 平均順位は期間内の平均で、日々の順位ではない。

## 3. 決めてほしいこと

1. 市場ごとの重点KWを、上の案から選ぶ（または差し替える）。各市場2〜3語が目安。
2. 検索ボリュームの確認（Googleキーワードプランナー等。`/create-market` Phase 0 の手動ステップ）。
3. 週次の更新方法：毎週、Search Consoleの「クエリ別」「ページ別」のCSVを渡す（Claudeが前週比を集計する）か、順位のスクリーンショットを渡すか。
