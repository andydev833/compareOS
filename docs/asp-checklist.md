# ASP案件の確認チェックリスト

- 作成日：2026-11-02
- 最初の対象：結婚式市場（ロードマップ「ASP案件・承認条件・地域制限を確認」、期限11/5）。転職市場など他の市場でも同じ表を使う。
- 使い方：ASPの管理画面で**あなたが**案件ページを開き、下の表の「確認した値」を埋める。埋めた表をそのままClaudeに渡すと、市場選定のスコアリング（収益化の軸）と、広告表記・計測の実装に反映する。
- ルール：管理画面に書かれている値だけを書く。**メモ内の報酬例は未確認の例示なので、事実として扱わない**。見つからない項目は「記載なし」と書く（空欄にしない）。ASPの規約や案件の注意書きは、要約せず原文の該当部分も貼る。
- Claudeはログイン・提携申請・規約への同意を代行しない（アカウント・法人情報の入力を伴うため）。

## 結婚式市場の特化テーマ（11/8に決める）との対応

テーマ候補（大型犬同伴／少人数／200万円以内／前撮り／プロフィールムービー）ごとに、上の表で見る観点：

- 該当するテーマを扱う広告主の案件があるか（成果地点が来店予約か成約か）
- 地域の制約で「大阪」が対象になるか
- 比較・ランキング形式の掲載が許されているか

この3点が揃う案件が多いテーマほど、収益化の軸の点が高くなる。
