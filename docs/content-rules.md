# コンテンツ生成ルール

## 書いてよいこと / 書いてはいけないこと

企業情報について確認できない内容を推測してはいけない。不明な場合は `null` または空配列を使う。

**明確に禁止**：

- 架空の料金
- 架空の口コミ
- 架空の実績
- 架空の店舗
- 架空の営業時間
- 架空のランキング根拠
- 根拠のない「おすすめNo.1」表現

## 情報源の保持

重要な企業情報には可能な限り `source` を保持する。

```json
{
  "url": "https://example.com/price",
  "type": "official",
  "checkedAt": "2026-07-31"
}
```

一次情報である公式サイトを優先する。

## Research と Strategy の分離

- **research.md** — 確認できた事実、SERP、競合、ユーザー検索意図、市場状況。事実のみを記載する。
- **strategy.md** — Researchを踏まえ、どのようなサイトで勝つかというAIの判断。事実と戦略判断を混同しない。

## 文章生成時のルール

- SEOキーワードを不自然に連呼しない
- 「おすすめ10選」のようなテンプレ量産だけにしない
- 比較理由を明示する
- 企業ごとの差異が分かるようにする
- 読者が次に何をすればいいか明確にする（CTA）
- 不明な情報を書かない
- 一般論と企業固有情報を区別する
- 同じ説明を複数ページへ大量コピーしない
